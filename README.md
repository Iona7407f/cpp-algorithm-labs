# C++ Algorithm Lab

Three standalone C++20 programs:

- `graph_algorithms` — BFS, DFS, and Dijkstra’s algorithm.
- `sorting_searching` — insertion sort, merge sort, linear and binary search, and merging sorted vectors.
- `complexity_algorithms` — operation counts for examples from O(1) to O(n!).

## Build

Requires CMake 4.2+ and a C++20 compiler.

```sh
cmake -S . -B build
cmake --build build
```

Run the executable for the program you want to try.
